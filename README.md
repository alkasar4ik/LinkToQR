# Link to QR

A simple desktop application built with **Python** and **Tkinter** that allows users to generate QR codes from links and save them as PNG images.

## Features

* Generate QR codes from any link
* Preview the generated QR code
* Save QR codes as PNG files
* Simple and easy-to-use interface
* Lightweight desktop application

## Technologies

* Python
* Tkinter
* QRCode
* Pillow

## Installation

Clone the repository:

```bash
git clone https://github.com/alkasar4ik/LinkToQR.git
```

Open the project folder:

```bash
cd LinkToQR
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## Run the Application

Start the application with:

```bash
python main.py
```

Enter a link, click **Create QR**, and the application will generate the QR code.
